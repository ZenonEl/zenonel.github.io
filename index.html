Keeping a project going between AI sessions

How they work together

A new session should be able to find the original requirement and see where the work stopped. These are the tools I use for the different parts of that job.

  • mnemo

    Keeps project messages and files with their sources, so an agent can trace a requirement back to where it came from.

  • herald

    Brings incoming material into an agent session and sends prepared replies through a configured communication channel.

  • ephemeris

    Keeps the work day in an issue and helps the next session pick up from source links and the current state.
