  • ephemeris

    Keeps the work day in an issue and helps the next session pick up from source links and the current state.

    Instruction package with one version check; no tests or CI

    • public repo
    • published spec
    • Repository
    Background and limits

    A work day usually outlives one agent session. Ephemeris records the state of the day in an issue and hands the next session addresses it can resolve: issues, comments, commits, paths, and mnemo citations.

    It is a package of agent instructions, not an application. Its only executable file checks version parity across the manifests and README badges. There are no automated tests or CI, and I would rather say that here than let the repository look larger than it is.

  • zapret2-nix

    A NixOS module and preset library that separates declarative configuration from runtime strategy switching.

    Public v0.1; module, presets and checks are available

    • public repo
    • published spec
    • Repository
    • Usage and design
    Background and limits

    I built it because the upstream NixOS module deliberately stops at raw service flags. This project adds a preset library, derives firewall ports from the same preset data, and lets a running machine switch strategy without a rebuild.

    The awkward cases are part of the design: a running bypass service can corrupt a strategy test, and a VPN can make every strategy look successful. The check wrapper stops the service for its run and refuses to treat a tunnel as useful evidence. Presets still depend on the ISP and can stop working when its DPI changes.
