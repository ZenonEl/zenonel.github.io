# zenonel.github.io

Bilingual portfolio and engineering case library for [ZenonEl](https://github.com/ZenonEl).

The repository contains the generated static site served by GitHub Pages. It has no runtime JavaScript, external font request, analytics, or build step on the public branch.

Site markup and supporting code are covered by [AGPL-3.0](LICENSE). Written portfolio content is published under [CC BY 4.0](LICENSE-CONTENT.md). Vendored fonts and icons carry their own licence files under `assets/`.
